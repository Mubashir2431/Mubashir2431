## About

I'm a Computer Science student at Drexel University (Pennoni Honors College, STAR Scholar) in Philadelphia. I build software with machine learning and LLMs inside it: serverless backends on AWS, agent and retrieval systems, and PyTorch models for biomedical signals.

- 🔬 **STAR Scholars researcher (Jun 2026 to present):** I train detection models on newborn EEG for a Drexel team working toward non-invasive fetal brain monitoring.
- 🤖 **AI Intern, TPS Worldwide (summer 2025):** I built an agentic KPI analytics assistant (CrewAI, RAG over FAISS, an MCP server to Elasticsearch) for a performance system covering 500+ employees.
- 🏆 **Hackathons:** Comcast AI Award and runner-up in Advanced at Philadelphia CodeFest 2026 (Mayday), 1st place at Drexel's Baiada Innovation Tournament (AfterHello), and the GalaxyGate track at the Coffee & Code Philly AI Agent Hackathon (Vault).

**Looking for:** Spring/Summer 2027 co-ops in software engineering, AI/ML, or data.
